# 포트폴리오 웹사이트

순수 HTML, CSS, JavaScript로 만든 2페이지 반응형 포트폴리오입니다.

## 실행 방법

1. 압축을 풉니다.
2. `index.html`을 더블 클릭합니다.
3. `index.html`, `activities.html`의 이름·소개·링크를 본인 정보로 바꿉니다.

## 파일 구성

- `index.html`: 자기소개 페이지
- `activities.html`: 활동 및 프로젝트 페이지
- `css/style.css`: 디자인과 반응형 레이아웃
- `js/script.js`: 모바일 메뉴, 다크 모드, 필터 기능

외부 서버나 설치 과정 없이 바로 실행할 수 있습니다. Google Fonts를 불러오므로 인터넷 연결이 없을 때는 시스템 글꼴로 표시됩니다.
